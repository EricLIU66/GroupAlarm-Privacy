隐私政策

了解 GroupAlarm 如何处理闹钟、假期及购买信息。

GroupAlarm 不要求注册账户。闹钟计划主要保存在你的设备上；获取公共假期数据及使用 Apple App 内购买功能时，会与相应服务通信。

隐私政策

生效日期：2026 年 9 月 27 日

本政策适用于 GroupAlarm iPhone 应用及此政策网页。下文中的“我们”指 GroupAlarm 开发者。

1. 设备上的数据

你创建的闹钟、群组名称、时间、重复规则、自定义假期、地区选择及应用设置存储在设备的应用数据区。GroupAlarm 使用 Apple AlarmKit 在设备上安排及管理系统闹钟。我们没有创建账户或云端同步服务，也不会将你的闹钟名称或计划上传至我们的服务器。

2. 公共假期数据请求

当你选择公共假期地区或更新假期数据时，应用可能向 Nager.Date（nagerholidays.com）请求可用地区或指定地区及年份的公共假期数据；中国内地假期数据可能从 GitHub 的 raw.githubusercontent.com 获取。部分年度数据已随应用提供，无需下载。这些请求会向数据提供者显示请求路径中的地区及年份，并可能使其获得连接所需的 IP 地址等网络信息。应用不会在请求中附上你的闹钟内容。数据提供者如何保存连接信息，由其各自政策决定。

3. 购买及系统服务

试用、一次性购买及恢复购买由 Apple StoreKit 和 App Store 处理。应用读取 Apple 验证的商品、交易及购买权益，以决定可用功能；我们不接收你的支付卡资料。Apple 可能按其政策处理购买信息。系统闹钟授权及排程由 iOS 管理。

4. 反馈、分析与分享

如果你主动使用应用内的“报告错误”，应用会打开邮件 App 并预填主题；只有你选择发送的内容才会传给我们。如果你通过下方联系入口与我们联系，你提供的信息会用于回复及处理请求。应用没有第三方广告或行为分析 SDK；我们不出售个人信息，也不使用数据进行跨应用追踪。

5. 保留、删除与选择

闹钟和假期数据保存在你的设备上，直到你在应用内删除、使用“重置所有计划”，或卸载应用。重置时，应用也会尝试取消相关系统闹钟；如取消暂时失败，应用会继续重试或提示你处理。购买记录由 Apple 按其政策保存。你可以在 iOS 设置中管理闹钟权限。

6. 此网页与政策变更

此静态网页由 GitHub Pages 提供，没有加入我们自己的 Cookie、分析脚本或追踪像素。GitHub 可能依其政策处理网页访问所需的信息。如果应用的数据处理方式有重大变更，我们会更新此页和生效日期。

7. 联系我们

如对隐私或数据删除有疑问，请通过 GitHub Issues 联系我们。请勿在公开 Issue 中发布个人或敏感信息。
