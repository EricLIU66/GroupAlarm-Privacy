隱私政策

了解 GroupAlarm 如何處理鬧鐘、假期及購買資料。

GroupAlarm 不要求註冊帳戶。鬧鐘計劃主要保存在你的裝置上；取得公共假期資料及使用 Apple App 內購買功能時，會與相應服務通訊。

隱私政策

生效日期：2026 年 9 月 27 日

本政策適用於 GroupAlarm iPhone 應用程式及此政策網頁。下文中的「我們」指 GroupAlarm 開發者。

1. 裝置上的資料

你建立的鬧鐘、群組名稱、時間、重複規則、自訂假期、地區選擇及應用設定儲存在裝置的應用資料區。GroupAlarm 使用 Apple AlarmKit 在裝置上安排及管理系統鬧鐘。我們沒有建立帳戶或雲端同步服務，也不會把你的鬧鐘名稱或計劃上傳至我們的伺服器。

2. 公共假期資料請求

當你選擇公共假期地區或更新假期資料時，應用可能向 Nager.Date（nagerholidays.com）請求可用地區或指定地區及年份的公共假期資料；中國內地假期資料可能從 GitHub 的 raw.githubusercontent.com 取得。部分年度資料已隨應用提供，無需下載。這些請求會向資料提供者顯示請求路徑中的地區及年份，並可能讓其取得連線必需的 IP 位址等網絡資訊。應用不會在請求中附上你的鬧鐘內容。資料提供者如何保存連線資訊，由其各自政策決定。

3. 購買及系統服務

試用、買斷及恢復購買由 Apple StoreKit 和 App Store 處理。應用讀取 Apple 驗證的商品、交易及購買權益，以決定可用功能；我們不接收你的付款卡資料。Apple 可能按其政策處理購買資料。系統鬧鐘授權及排程由 iOS 管理。

4. 回饋、分析與分享

若你主動使用應用內的「報告錯誤」，應用會開啟郵件 App 並預填主旨；只有你選擇發送的內容才會傳給我們。若你透過下方聯絡入口與我們聯繫，你提供的資料會用於回覆及處理請求。應用沒有第三方廣告或行為分析 SDK；我們不出售個人資料，也不使用資料作跨應用追蹤。

5. 保留、刪除與選擇

鬧鐘和假期資料保存在你的裝置上，直到你在應用內刪除、使用「重置所有計劃」，或移除應用。重置時，應用亦會嘗試取消相關系統鬧鐘；如取消暫時失敗，應用會繼續重試或提示你處理。購買記錄由 Apple 按其政策保存。你可以在 iOS 設定中管理鬧鐘權限。

6. 此網頁與政策變更

此靜態網頁由 GitHub Pages 提供，沒有加入我們自己的 Cookie、分析腳本或追蹤像素。GitHub 可能依其政策處理網頁訪問所需的資訊。若應用的資料處理方式有重大變更，我們會更新此頁和生效日期。

7. 聯絡我們

如對隱私或資料刪除有疑問，請透過 GitHub Issues 聯絡我們。請勿在公開 Issue 中張貼個人或敏感資料。
